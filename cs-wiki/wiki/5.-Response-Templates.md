# Response Templates

Ready-to-use templates for common CS interactions.

*Goal: To provide a library of standardized responses to ensure speed and accuracy in every customer interaction.*

  

## **Section Overview**

Response Templates are the practical application of our Playbook. They are designed for both manual use and AI automation to deliver consistent results across all support channels.

  

## **Core Principles**

- **Operational Speed**: Pre-written templates reduce response time and ensure accuracy during high-volume periods.

- **Format Uniformity**: Standardized HTML snippets ensure a professional visual experience for the recipient.

- **Personalization Rule**: Templates are frameworks; always include specific identifiers (Student ID, Class ID) before sending.

- **Article State Lifecycle**: Every template has a state: WIP (Work In Progress) → Not Validated → Validated → Archived. Review and update state regularly to prevent outdated responses.

  

## **Key Sub-sections**

- **[5.1 Acknowledgment](5.-Response-Templates/5.1-Acknowledgment)**: Send within SLA response time. Confirm receipt, set expected resolution timeline, include ticket ID. Use for all new tickets.

- **[5.2 Status Updates](5.-Response-Templates/5.2-Status-Updates)**: Send every 24h if ticket not resolved. Acknowledge delay, state current action, give next update time. Use for tickets on hold.

- **[5.3 Resolution Confirmed](5.-Response-Templates/5.3-Resolution-Confirmed)**: Send after verifying fix with student. Include what was fixed, next steps (if any), and confirmation prompt. Use to close the ticket.

- **[5.4 Negative Outcomes](5.-Response-Templates/5.4-Negative-Outcomes)**: Use when a request cannot be fulfilled or is rejected. Explain reason clearly, provide alternative if available, avoid blame.

- **[5.5 Template Description](5.-Response-Templates/5.5-Template-Description)**: Browse to find the correct template match. Check Article State before using — do not use Archived templates. Use the Usage Description to distinguish similar templates.
