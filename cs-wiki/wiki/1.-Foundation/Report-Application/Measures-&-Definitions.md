# Measures & Definitions

## S&M Measures (Sale & Marketing)

### Order Management

| Measure | Description |
|---------|-------------|
| Revenue | Số tiền thực nhận từ khách hàng |
| Student seat | Số HS đăng ký học (đã đóng > 5.500.000 VND hoặc > 17.000.000 VND khóa bảo trợ) |
| APV | Giá trị TB 1 SP. APV = Revenue after discount / Total paid product item |
| AOV | Giá trị TB 1 đơn hàng. AOV = Revenue before discount / Total number of order |
| ANSV | Doanh thu thực trên 1 HS. ANSV = Net revenue / Student seat |
| Paying customer | Số KH đã trả tiền |
| Paid product item | Số lượng SP đã trả tiền |
| Unconfirmed payment | Số tiền KH trả nhưng chưa được KT xác nhận |
| Total payment amount | Tổng tiền KH trả (đã xác nhận + chưa xác nhận) |
| New Revenue | Doanh thu từ order mới phát sinh payment lần đầu trong tháng (ko tính thu nợ tháng trước) |

### Sale Funnel

| Measure | Description |
|---------|-------------|
| L1-L6 | Số lead ở trạng thái L1-L6 trong thời gian filter |
| NL1-NL6 | Số lead mới tạo trong thời gian filter, chuyển lên các stage |
| CR12/CR23/CR34/CR45/CRX5 | Tỷ lệ chuyển đổi giữa các stage |
| ACT 15 | Thời gian chuyển đổi TB L1→L5 |

### MKT Measures

| Measure | Description |
|---------|-------------|
| CAC | Customer Acquisition Cost = ME / Paying customer |
| CPAC | Cost Product Acquisition Cost = ME / Paid product item |
| ME | Marketing Expense (chi phí MKT) |
| CPL1 | Cost Per Lead L1 = ME / L1 |
| CPL3 | Cost Per Lead L3 = ME / L3 |
| CPPL | Cost Per Paying Lead = ME / Paying lead |

### Churn Reason
- **L3 Churn**: Lý do KH không còn quan tâm
- **L4 Churn**: Lý do KH không tham gia trải nghiệm / tham gia nhưng không mua
- **L5 Churn**: Lý do KH không tiếp tục mua hàng
- **All Churn**: Tất cả lý do trong mọi stage

## OPS Measures

| Measure | Description |
|---------|-------------|
| Completion Rate | Tỷ lệ HS hoàn thành khóa học |
| Retention confirmation rate | Tỷ lệ HS xác nhận học khóa tiếp theo |
| Retention Confirmed | Số lượng HS xác nhận học khóa tiếp theo |
| Student Attended | Số HS được điểm danh ít nhất 1 buổi (lớp kết thúc trong time range) |
| Absent student | HS vắng 2 buổi liên tiếp |
| Absent student rate | Tỷ lệ HS vắng 2 buổi liên tiếp |
| Demo day's score | Điểm kết thúc khóa học |
| Package progress — Enrollment needed | Số lớp HS có thể học tiếp |
| Package progress — Up sale/Resale needed | Số HS cần upsale/resale |

### Student Status

| Status | Định nghĩa |
|--------|-----------|
| Active student | HS đang ở trong lớp Running |
| Inactive student | HS ko trong lớp nào hoặc lớp ko Running |
| On-hold student | HS đang bảo lưu |
| Onhold expired student | HS hết hạn bảo lưu chưa đi học lại |
| Dropout student | HS nghỉ trước khi hoàn thành |
