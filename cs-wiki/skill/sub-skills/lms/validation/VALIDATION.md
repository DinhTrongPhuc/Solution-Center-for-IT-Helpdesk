# Validation Checklist

Before answering:
1. **Wiki searched** — tool executed
2. **Source cited** — answer includes file + section
3. **GitBook flow** — if not in wiki, checked GitBook → updated wiki
4. **No direct GitBook citation**
5. **Conciseness** — short, no preamble
6. **Accuracy** — content matches wiki
7. **Not found case** — "Chưa có trong wiki LMS"
