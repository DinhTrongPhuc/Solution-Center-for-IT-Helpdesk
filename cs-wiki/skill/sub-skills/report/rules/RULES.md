# Rules

1. **Never guess** — only use content from wiki files. Do not invent features.
2. **Source from wiki only** — do not cite GitBook directly. If content comes from GitBook, update wiki first.
3. **Search before answering** — always search wiki with **Grep** tool first.
4. **Always cite sources** — include file, section.
5. **Distinguish intent** — classify as "how-to" / "data inquiry" / "bug" before processing.
6. **Not found -> check GitBook** — if wiki search returns nothing, check GitBook via MCP. Update wiki -> answer from wiki.
7. **Not found anywhere** — "Chưa có trong wiki Report Application"
8. **Do not modify files** without user instruction.
9. **Report source always** — include file path and section.
10. **Luôn đưa ra lưu ý** — khi trả lời bất kỳ câu hỏi nào, luôn kiểm tra và đưa ra các mục "lưu ý", "note", "warning" liên quan.
11. **Q&A Report dùng tiếng Anh** — luôn nhắc user dùng tiếng Anh khi tra cứu Q&A Report.
12. **Redirect CRM/LMS built-in reports** — nếu user hỏi về CRM/LMS report cũ -> "Đã chuyển sang Report Application. Dùng skill Report để tra cứu."
