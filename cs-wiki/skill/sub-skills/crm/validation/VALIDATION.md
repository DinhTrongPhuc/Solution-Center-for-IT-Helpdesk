# Validation Checklist

Before answering, verify:

1. **Version detected** — v1 or v2 confirmed (or asked user)
2. **Wiki searched** — tool executed with appropriate query and mode
3. **Source cited** — answer includes file, section, and version tag
4. **GitBook flow followed** — if not in wiki, checked GitBook → updated wiki → answered from wiki
5. **No direct GitBook citation** — answer cites wiki, not GitBook URL
6. **Conciseness** — answer is short, no unnecessary preamble
7. **Accuracy** — content matches the wiki section exactly
8. **Tag match** — answer uses correct `[v1]`/`[v2]`/`[v1+v2]` tag matching user's version
9. **Not found case handled** — "Not yet documented in wiki" if truly missing
